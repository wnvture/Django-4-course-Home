# Устройство проекта

Серверный Django с HTML-шаблонами. Все основные формы работают без JavaScript. Локальные CSS и изображения, без внешнего CDN.

| Модуль | Ответственность |
| --- | --- |
| `goods` | Каталог, цены, SKU, CSV-импорт и отчёты |
| `carts` | Корзина пользователя или гостевой сессии, проверка принадлежности |
| `orders` | Транзакционное оформление, снимки названия и цены |
| `users` | Вход, регистрация, профиль и собственные заказы |
| `main`, `common` | Главная, общие контекстные данные |

## Оформление заказа

`orders/services.py` блокирует пользователя и товары в постоянном порядке, проверяет весь заказ, списывает остатки условными SQL-обновлениями, создаёт позиции со снимком цены и очищает корзину в одной транзакции. Ошибка откатывает все изменения. Уникальный токен защищает от двойного нажатия кнопки.

Блокировка строк действует в PostgreSQL. SQLite не даёт тех же гарантий конкурентной работы, поэтому используется для локального запуска. В PostgreSQL тест двух параллельных покупателей проверяет, что последнюю единицу получает только один из них.

Корзины не резервируют склад. Вход объединяет гостевые и сохранённые позиции, не удаляя прежнюю корзину. Суммарное количество ограничено диапазоном поля, наличие проверяется при изменении корзины и при оформлении.

## Импорт

`goods/importing.py` разбирает и проверяет весь CSV, затем сохраняет предпросмотр с нормализованными строками и исходным состоянием товаров. Применение блокирует пакет и товары, сверяет состояние с предпросмотром и сохраняет все строки в одной транзакции. Старый предпросмотр не может затереть продажу или чужое изменение. Параллельные попытки создать один SKU/название ограничены уникальными индексами; конфликт откатывает пакет.

Повторное применение одного пакета идемпотентно. Два разных файла считаются разными пакетами, даже если совпадает их хеш. Пакет содержит только свои строки: отсутствие товара в CSV его не удаляет.

## Доступ

Профиль и история ограничены текущим пользователем. Изменение корзины проверяет владельца. Рабочий кабинет доступен только `is_staff`; применить пакет может только его автор. Формы защищены CSRF, выход выполняется POST-запросом, внешние адреса возврата после входа/корзины не принимаются. Данные товаров выводятся с HTML-экранированием.

Денежные значения хранятся в `Decimal`; цена продажи округляется до 0,01 по `ROUND_HALF_UP`. Стоимость остатков — количество × текущая цена продажи, без учёта себестоимости и налогов. Отчёт показывает стоимость всего каталога, а поисковые фильтры ограничивают таблицу и CSV-экспорт.

Это ограниченная учебная модель: склад без резервов, один набор цен в KZT, оплата при получении без финансовой интеграции. Заказы и их позиции не создаются/удаляются из админки, снимки цены доступны только для чтения. Изменение статуса не возвращает товар на склад.
